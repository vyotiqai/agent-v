# Agent V

A personal AI agent for iPhone and Android. You hand it outcomes; it plans, works in the
background around the clock, and only interrupts you when it needs you.

**Status: design complete.** All seven design stages are agreed. Building follows the
[build plan](docs/design/07-build-plan.md): small slices, each working end to end and verified
before the next, starting with slice 0 (foundations). Start with the
[design overview](docs/design/README.md).
